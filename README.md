# Book Scanner

A simple personal book library app that runs directly in your browser. It lets you:

- scan a book image or cover using OCR
- save books to local storage
- search your library
- switch between multiple themes
- export your library as JSON, CSV, or PDF

## Features

- OCR library scan using Tesseract.js
- Mobile-friendly camera upload support
- Personal book library with notes and status
- Search by title, author, or ISBN
- Theme switching: Classic, Dark, Sunset, Forest, Midnight
- Export data to JSON, CSV, and PDF

## Run locally

1. Open the project folder in your browser.
2. Open `index.html` directly, or serve it with a local static server.

Example using Python:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Files

- `index.html` – app structure
- `styles.css` – theme system and layout
- `app.js` – logic for OCR, storage, search, and exports

## Notes

This project is designed for personal use and runs entirely in the browser without a backend.
